This repository contains the optimized, production-grade **PostgreSQL** solutions for all **66 interview questions** covered in the course. Questions are sourced directly from real-world tech interviews (FAANG, Tier-1 Tech, and FinTech) via StrataScratch.

---

## 🧠 How to Use This Repository

1. **Find the question** you want to practice in the index below.
2. **Attempt it yourself** on StrataScratch first.
3. **Stuck?** Click the `[ 🎥 Watch ]` link to jump to the exact second I solve and break down that specific problem in the video.
4. **Compare syntax:** Open the corresponding `.sql` file inside the `/solutions` folder to view my finalized code.
